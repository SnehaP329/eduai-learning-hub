# EduAI Learning Hub 🎓

**EduAI Learning Hub** is an easy-to-use, interactive website built with **Streamlit**. It acts as a personal AI study buddy that helps students easily understand the topics.
**Listen & Learn:** Uses built-in voice tools (**gTTS**) to read explanations, giving you a choice between speed and the target voice profile.
